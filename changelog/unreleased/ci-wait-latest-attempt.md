### Added

- **`nx ci wait --latest-attempt` follows a re-run.** By default the wait returns the newest `--done` row for the sha already on the board, which after a re-run starts is still the row of the attempt being replaced. With `--latest-attempt` a row counts only when GitHub's push runs show no newer attempt of any run in it; otherwise the wait goes on for the newer attempt's row (GitHub read at most once a minute), reports from GitHub when that attempt has finished but its row never came, and times out while it still runs. A green row GitHub could never confirm exits 4, not 0. It cannot be combined with `--fresh` (exit 5).
