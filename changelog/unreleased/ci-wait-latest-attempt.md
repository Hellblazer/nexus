### Added

- **`nx ci wait --latest-attempt` follows a re-run.** By default the wait returns the newest `--done` row for the sha already on the board, which after a re-run starts is still the row of the attempt being replaced. With `--latest-attempt` a row counts only when GitHub's push runs show no newer attempt of any run in it; otherwise the wait goes on for the newer attempt's row (GitHub read at most once a minute), reports from GitHub when that attempt has finished but its row never came, and times out while it still runs. A failed GitHub read is retried and never accepts a row; when GitHub stays unreadable throughout, the row is held until `--timeout`, then printed with exit 4 if it is green (not 0) and 1 if it is red. It cannot be combined with `--fresh` (exit 5).
