### Added

- An opt-in end-to-end gate, `tests/e2e/compact-outcome-gate.sh`, drives a real `claude` through a real automatic compaction and scores whether the session then acts on its open items with no user input. Its arms are the shipped compaction hooks (`real`), no plugin (`control`), a planted-bad checkpoint (`bad`) and a harness-owned candidate-fix overlay (`fix`); it exits 0 only when `real` reaches the threshold and `bad` and `control` do not, and 2 (never a pass) when any run ends with no verdict, no compaction is seen, or the hooks did not run. It spends model calls, so it is run by hand: no workflow, script or default pytest run starts it, and `tests/hooks/test_compact_outcome_harness.py`, which starts no `claude`, pins that. The stub `nx` answers every call today's checkpoint hook makes (the identity-line board search, the board fetch, the continuation call, the running-work listing), the harness test fails when the hook gains a call the stub does not answer, and the live run's environment drops the parent session's identity and session markers and binds no identity.
