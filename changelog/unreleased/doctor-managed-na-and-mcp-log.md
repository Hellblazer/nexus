### Fixed

- **`nx doctor` on a managed deployment shows the eight database rows as not applicable, not as warnings.** Storage service health, Schema migrations, RLS policies, tuples.dead_tuple_ratio, tuples.sweep_freshness, Tenant partitions, Model partitions and Partition leaves read the database with local admin credentials that a managed deployment keeps with the store operator. They now print `[ ]` with "managed deployment, not probeable from this client, so this check was not run", count in neither the warnings nor the verdict, and never show a checkmark. A local install runs and judges them as before.
- **`mcp.claude_code_connection` no longer reports a weeks-old failure as the latest connection.** Run from a directory whose only ancestor log directory was `/`, it read a stale log and reported "ENOENT, executable not found: stdio" while the server worked. It now searches every project directory Claude Code writes under when the current directory's own hold no recent log, and a log last written more than 7 days ago is not judged: the row says "no recent connection log".
