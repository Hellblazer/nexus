### Fixed

- **The `search` MCP tool shows an identical chunk once, not once per collection** (GitHub #1524). The same text indexed in several collections (the RDR template's README, byte-identical in every repo that ships it) is one chunk in each and used to rank first once per collection. `search` now keeps the best-ranked row and names the other collections on it: an `also in:` line in the text result, and an `also_in` list aligned with `ids` in the `structured=True` result, present only when some row has copies. `query` and `nx_answer` have done this since 7.38.0. Re-indexing a repo with `nx index repo` also removes a stored RDR-directory README.
