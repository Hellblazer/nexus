### Fixed

- **`/conexus:nx-preflight` no longer reports a healthy `nx doctor` as unavailable.** `nx doctor` took about 45 s on a healthy install and the preamble bounded it at 15 s, so check 2 could never pass. Doctor now has its own bound (`_DOCTOR_TIMEOUT`, 120 s), a timeout says "nx doctor exceeded 120s; not a failure; run 'nx doctor' directly", and a local engine that does not answer `/health` within 5 s is reported at once instead of after the long bound (GH #1689).
- **The preamble's CLAUDE.md language check stops guessing.** It matched case-insensitively, so the verb "go" read as Go, Java matched inside JavaScript and Rust inside "rusty", and Lua was missing. Languages are now case-sensitive proper names with word boundaries, Go needs a stronger cue than its name (a version, Golang, `go.mod`, a go tool command), and Lua is detected (GH #1689).
- **A `bd` with no beads database is no longer reported as "printed nothing" or "unavailable or no results".** `nx brief beads` and the `nx command-context` beads blocks now say "there is no beads database here" for that case, and name the exit code and first stderr line for any other `bd` failure or timeout. The console's needs-sam read, `nx brief` and the preamble share one detector, `nexus.beads_state` (GH #1689).
