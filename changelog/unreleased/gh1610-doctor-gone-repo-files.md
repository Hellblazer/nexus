### Fixed

- **`nx doctor` names repo documents whose files are gone, and the command that removes them** (GH #1610). The stale index-run fence row listed repo documents whose files had been deleted and offered only `nx index <path> --force`, which cannot re-index a file that no longer exists. When the repo is on this machine, the row now checks each named document's file against its owner's repo root, counts the missing ones on their own, and points them at `nx catalog prune-stale --owner <prefix>`; `--force` is no longer offered for a document whose file is known to be gone. `nx catalog reconcile-fences` names `prune-stale` beside `--force` for the repo documents it skips, and `prune-stale`'s help says it also checks relative paths under the owner's repo root.
