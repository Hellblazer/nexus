### Fixed

- **conexus agents no longer ask the model to make its reasoning visible.** On conexus 8.3.0 the API safety classifier stopped substantive-critic runs in RDR gates, and some code-review-expert dispatches, with `[reasoning_extraction]` (GH #1661). The SubagentStart hook lost its sequential-thinking section in 8.2.2 (GH #1656), but ten agent definitions still told the model to use the sequential-thinking tool before every verdict or decision, called the thought chain "the visible record" of its reasoning, and gave a numbered Thought 1-8 template. Those sections, templates and tool mandates are removed from architect-planner, code-review-expert, codebase-deep-analyzer, debugger, deep-analyst, deep-research-synthesizer, developer, strategic-planner, substantive-critic and test-validator, and the visible-record sentence from the orchestration skill's Working Rules. Each agent's method (hypotheses, evidence, file:line findings, verdicts) is unchanged. The sequential-thinking MCP server itself stays.
