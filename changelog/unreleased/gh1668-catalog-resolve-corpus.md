### Fixed

- **`resolve(corpus="rdr")` returned an empty list although `rdr__*` collections existed.** The MCP tool `resolve` matched `corpus` only against the free-form `corpus` label on documents, which the indexers do not set to a content type by default. `corpus` now also accepts a collection content type (`code`, `docs`, `rdr`, `knowledge`) and returns its live collections, together with any label matches. A value that is neither a content type nor a label any document carries is an error that names the value and lists the valid content types, so an empty list means only "no live collections of that content type". The CLI had no equivalent: new `nx catalog resolve [TUMBLER] [--owner] [--corpus] [--json]` shares the same function (GH #1668).
