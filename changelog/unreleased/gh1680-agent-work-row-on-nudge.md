### Fixed

- **A dispatched agent's `agent:<id>` work row is removed at every stop, nudged or not (gh#1680).** The SubagentStop T1 nudge removed the row only when it returned no nudge, and expected a second stop after the nudge that a read-only agent ending with its hand-back often never makes, so the row stayed `running` for the life of the session and the restart ready check and the compaction checkpoint reported an agent that had finished. The stop now removes the row in every case; the removal is idempotent, so the re-stop after a nudge repeats it harmlessly. The row ends at the nudging stop, not at the agent's last turn, so the extra turn a nudge buys is invisible to the ready check and the compaction checkpoint; that is deliberate, because waiting for a second stop is what left the row running.
- **`nx brief me` no longer suggests a write the identity would refuse (gh#1680).** With no startup note, an ephemeral or delegated identity was told to run `nx memory put --mine`, which the client refuses for it. The line now carries the identity guard's own reason for that caller (a delegated or ephemeral identity keeps no identity notes and is told to write the note in project T2; a lookup the engine did not answer prints a "could not confirm" line); a seat still gets the `--mine` command, and a failed lookup gives a neutral hint without failing the topic. The check is `notes.write_refusal`, a side-effect-free predicate that `check_write` raises from, so a read leaves no `identity_notes_write_refused` log line.
