### Added

- **`scripts/lab-preflight` tells `lab-remote` before dispatch that a pytest run would be refused at once (labrun-0uy.2.4).** Run as `python3 scripts/lab-preflight -- <argv...>` in the host copy, it exits 75 with one line, "prepend `scripts/build-gate-jar.sh`", when the command is a pytest run that can boot the engine substrate (`NX_TEST_T2_SUBSTRATE` is not `none` or a retired value) and `service/target/nexus-service-1.0-SNAPSHOT.jar` is not built. A `lab-remote` copy has no `service/target/`, so the first engine-substrate run used to queue for a hand grant and then exit 75 within seconds (151 such grants since 10-18). A held suite lease or service build lease only warns on stderr and exits 0, since a lease can be gone by the time the run leaves the queue. Stdlib only, no network, no engine.
