### Added

- **`nx memory gate-rollup` lists a closed phase's gate records and writes a pointer record to T3.** `nx memory gate-rollup --rdr N (--phase P --beads b1,b2,... | --all) [--project REPO] [--dry-run]` reads the repository's T2 project once, matches whole tags (`kind:gate` with `bead:<id>`, or with `--all` `rdr:<NNN>`), and writes one T3 note, `gate-records-rdr-<NNN>-phase-<P>` (or `-all`) in the knowledge subject `nexus-rdr-research`, category `gate_pointer`, that lists each record's title, kind, bead, reviewed sha and verdict. Records with no readable verdict are listed as unmapped. A pointer over the 16,384-byte store_put cap is written as titled parts. It writes nothing to T2 (RDR-209 Phase 3 Step 1; the TTL is Step 3). The `phase-review-gate` and `rdr-close` skills name the command.
