### Changed

- **Wire pairing reports on develop and blocks on the release PR into main and in the engine release.** `ci.yml`'s `test-lint` job sets `NX_WIRE_PAIRING_MODE` to `block` for a pull request into main and `report` for every other event; in `report` mode `tests/test_wire_contract_pairing_lint.py` turns the pairing check's exit 1 (an undeclared both-halves commit, or a stale ledger entry) into a pytest warning, a job-summary entry and a `::warning::` annotation instead of a red job, and `scripts/meta_tests.py` runs the lint bucket in that mode. The push gate's `wire-ledger` check prints `PUSH_CHECK_REPORT wire-ledger` with the check's output and lets the push go on (`reported=wire-ledger` on the `PUSH_CHECKS_PASSED` line). Only the check's own finding is demoted, an exit 1 whose output carries the `UNDECLARED (n)` or `STALE (n)` header: a crashed script's traceback (also exit 1), a check that could not read git (exit 2), a missing script and a pass with no marker still fail or refuse in every mode. The ledger's format is unchanged (nexus-2jomg.3).
