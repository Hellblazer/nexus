### Changed

- **Wire pairing reports on develop and blocks on the release PR into main and in the engine release.** `ci.yml`'s `test-lint` job sets `NX_WIRE_PAIRING_MODE` to `block` for a pull request into main and `report` for every other event; in `report` mode `tests/test_wire_contract_pairing_lint.py` turns the pairing check's exit 1 (an undeclared both-halves commit, or a stale ledger entry) into a pytest warning and a job-summary entry instead of a red job. The push gate's `wire-ledger` check prints `PUSH_CHECK_REPORT wire-ledger` with the check's output and lets the push go on (`reported=wire-ledger` on the `PUSH_CHECKS_PASSED` line). Only exit 1 is demoted: a check that could not read git (exit 2), a missing script and a pass with no marker still fail or refuse in every mode. The ledger's format is unchanged (nexus-2jomg.3).
