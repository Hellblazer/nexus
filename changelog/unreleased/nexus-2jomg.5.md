### Added

- **`NX_LEDGER_MODE=report|block`: one switch for the three class-A ledger checks (RDR-258 Phase 4).** The plugin ledger (`tests/test_plugin_release_drift_ledger.py`), the changelog fragments (`scripts/changelog_fold.py check`, also `--mode`) and the cloud-leg route ledger (`tests/scripts/test_cloud_leg.py`) list a finding instead of failing it when the variable is `report`: one `LEDGER-FINDING <ledger>: ...` line each (a `::warning::` annotation too under GitHub Actions) and one `LEDGER-REPORT <ledger>: N finding(s), M item(s) examined` line. A check that examined nothing still fails. Unset or `block` is today's behaviour, and any other value is an error. The push gate runs the three under the same switch (`Spec.default_mode`, `block` for all) and relays a passing report's lines as `PUSH_CHECK_REPORT`. Nothing is turned to `report` yet. Helper: `scripts/ledger_mode.py`.
