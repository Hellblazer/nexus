### Changed

- **The RDR gate is keyed to the RDR file's blob, so a rebase before landing no longer orphans the gate record** (nexus-3jjkg). `nx rdr preamble rdr-verdict` now prints `blob:` (`git rev-parse --short=12 HEAD:<rdr file>`) in the gate record, names the blob in the suggested `fix_check:` pointer and in the Revision History line (`blob <sha>` where it printed `commit <sha>`), and still writes `commit:`. The re-gate block, the `rdr-fix` preamble, accept's gate-record check and the SessionStart `rdr` hook compare the file at HEAD against the gated blob, so a rebase or reset that leaves the text alone reads as "no change", and an edit is still found. The fix-check title is `{id}-fix-check-<blob>`, the blob of the file as it stands. The fix commits are listed from `commit:` while it resolves, and the section says so when it does not. A record written before this change carries only `commit:` and behaves exactly as before; nothing rewrites one. `tests/test_docs_reference_rot.py` now resolves a cited blob that a published commit carries, so a Revision History line naming a blob needs no allowlist row. The `rdr-gate-checklist`, `rdr-fix-checklist` and `rdr-accept-checklist` skills state the blob rule. The `src/nexus/hooks/rdr_verb.py` change reaches users with the next plugin release.
