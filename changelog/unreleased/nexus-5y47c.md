### Fixed

- **The subagent git-write guard no longer denies read-only git or text that spells a verb.** In the three weeks to 2026-11-25 it denied 2,199 subagent Bash calls, and 97% were not the harm it exists for: `git merge-base A $m`, `git stash list | head`, `git log --grep=commit`, `grep push scripts/git-push-develop.sh`, `cd <worktree> && git add`, a plain `git fetch`. It now reads the command with a strict lexer and judges each segment: a read-only git shape or a text command (`grep`, `cat`, `echo`, `ls`) may spell any verb word in its arguments, and a segment it does not recognise must pass the old rule on its own text. A command that holds a heredoc, a backtick, a comment, a brace, a backslash outside double quotes, an interpreter (`python`, `sed`, `eval`, `xargs`), a `git config` segment, or text that reaches a command through a pipe, a file, a variable or an alias is not admitted, and the old verdict stands. `checkout`, `stash`, `restore`, `reset --hard`, `clean`, `rebase --abort` and any write in the primary checkout stay denied.
- **A subagent may chain writes in a worktree git proves, push its own branch, and take three more shapes.** `git -C <worktree root> <verb> ...` calls chained with `&&` or `;`, and `cd <worktree root> && git <verb> ...` (a `cd` counts only along its `&&` run, or after `|| exit`), pass with the same verbs and flags as the single `git -C` shape, plus the long spellings `--quiet`, `--verbose`, `--dry-run` and `merge --no-commit`. `git push [-u] origin HEAD` (or the branch name) passes for the branch that worktree has checked out, never `develop`, `main` or `master`, never with `--force`, `--delete`, `--mirror` or a refspec naming another branch. `git fetch` passes unless it has a refspec destination, a `+refspec`, `--prune` or `-f`. `git worktree add --detach <absolute path outside every repo>` passes. A scratch repository the same command creates under a temporary directory (`git init`, `git clone`, then `config user.name|user.email`, `add`, `commit`) passes.
- **The deny text is under half as long (2.9 KB to 1.3 KB).** It says what was denied, the one allowed shape and who to ask. The long config and side-effect addenda are unchanged and still appear only for those denials. The implementer relay and the orchestration skill say what a brief gives a subagent about git: the worktree root, provisioned before dispatch; the one shape; who pushes.
