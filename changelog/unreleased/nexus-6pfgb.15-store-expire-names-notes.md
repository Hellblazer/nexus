### Fixed

- **`nx store expire` names every note it retires, and has a `--dry-run`.** It used to print "Expired 4 entries. 4 notes retired; 4 chunks deleted." and name none of them. It now prints one line per retired note (collection, title, tumbler, the instant its TTL ran out) before the totals. `--dry-run` runs the same judgement (each note's own catalog TTL, the stale-TTL guard, the chunk-row scan for notes put before the catalog held TTLs) and writes nothing: it lists "would retire" lines and the chunks the real run would send to the delete, and a note it could not judge is still an exit 1. The sweep now lives in `nexus.db.expire_sweep`; `nexus.db.http_vector_client` still exports `ExpireReport` and `ExpireIncompleteError`, and `HttpVectorClient.expire_report` takes `dry_run`.
