### Changed

- **MinerU's pipeline weights come from a nexus release asset, not Hugging Face (nexus-7t3w1, F35).** The 20 files the English pipeline loads are pinned by size and sha256 and published as individual assets of the immutable `mineru-pipeline-ed6b654c` release on Hellblazer/nexus. They land in `~/.cache/nexus/mineru/`, and every MinerU process nexus starts (the server, the per-batch worker, the `nx doctor --check-mineru` probe) is pointed at that copy through `MINERU_MODEL_SOURCE=local`, a nexus-owned `mineru.json` (a copy of yours with `models-dir.pipeline` set; your file is never written) and `HF_HUB_OFFLINE=1`. The release assets carry the AGPL-3.0 and Apache-2.0 texts and per-model notices. What it means per machine, one line each:
- **Fresh install:** the first PDF-indexing command downloads the 20 files, about 1.26 GB, from the nexus release asset, as a visible step before the first page.
- **Existing install whose Hugging Face cache has the files (any revision, matched by sha256):** links or copies them in with no download. A copy across filesystems costs a second 1.2 GB on disk, and deleting the Hugging Face cache afterwards does not free the space of a linked file.
- **Existing install with other or partial bytes:** downloads only the files that do not verify. If a usable Hugging Face cache remains and the download cannot finish (offline, GitHub blocked), MinerU keeps reading that cache as before and the run prints a warning instead of exiting 75.
- **`MINERU_MODEL_SOURCE=local`:** untouched; those are your models and nexus sets nothing. Any other value (unset, `huggingface`) is bypassed for nexus's own processes once its copy is complete. `modelscope` keeps working from its own source if the nexus download fails (and under refuse, when local copies cannot supply every missing file); `NX_MINERU_WEIGHTS_BASE_URL` can point the download at a mirror.
- **`MINERU_FORMULA_CH_SUPPORT` on:** unchanged F34 behaviour, fetched from Hugging Face, because the PP-FormulaNet model is not among the hosted files; with `MINERU_MODEL_SOURCE=modelscope` it gets no prefetch.
- **Background runs under `NX_PDF_STACK=refuse` (the post-commit hook):** seed only when local copies supply every missing file, with no network and without waiting on another run's lock. Otherwise they do nothing if a usable fallback exists (a complete Hugging Face cache, or the `modelscope` source), or hold the PDFs.
- **Offline with no usable Hugging Face cache and not on `modelscope`:** exit 75 with the retry advice (run again to resume, set a mirror, or use your own models with `MINERU_MODEL_SOURCE=local`).
- **A MinerU server that is already running:** its model source is fixed when it starts, so the PDF extractor restarts it once when it was started on MinerU's own source and nexus's copy is now complete (an old install, or a server the upgrade restart started before the weights were in place), unless `mineru_autostart` is off or the restart budget is spent. A server already on nexus's copy is never restarted back. It reads nexus's copy of `mineru.json`, refreshed when the server is spawned, so an edit to `~/mineru.json` reaches it after `nx mineru stop` and `nx mineru start`.
- **`NX_MINERU_WEIGHTS_BASE_URL`:** points the download at a mirror that holds the release assets, for a machine where GitHub is blocked.
