### Changed

- **A grown plan serves a lookup or a listing only when it recorded a fitting kind** (nexus-a4g2a). A grown plan whose kind was never decided no longer serves a lookup or a discovery/listing request (`grown_route_unrecorded`), and a discovery/listing request takes only a grown plan that recorded discovery (`grown_route_not_discovery`, counted per recorded kind in `plan_eligibility.refused_recorded_kinds`). This is a guard, not a measured effect: the plan library holds five grown plans and none has accrued since 2026-11-07. It only narrows which plans may serve, so the worst case is that `nx_answer` plans the request inline instead; a good match can be lost (grown plan 585 once served a discovery request well). A grown plan that recorded lookup still serves lookups.
