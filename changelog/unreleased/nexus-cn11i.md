### Changed

- **No conexus session or skill rule tells an agent to use the sequential-thinking tool any more.** A measured comparison on 2026-11-18 (nexus-cn11i, GH #1661; Opus 5.5, three runs an arm) found what triggers the API classifier's `[reasoning_extraction]` stops: guidance in the system prompt to log reasoning steps, together with a task message that asks for a number of recorded steps. The stop came with or without the tool loaded, and whether or not the task named the tool. Guidance alone, a demand alone, and guidance with a task that only names the tool all ran clean. The SessionStart guidance drops its "Sequential thinking before dispatch, a fix, ..." sentence, and the orchestration skill's Working Rules describe the tool as a step log with no mandate and ask briefs never to demand a count of reasoning steps. The deep-analysis preamble tip no longer names the tool. The tool and its step-log description stay.
