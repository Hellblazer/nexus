### Added

- **Each `nx` invocation and each MCP tool call gets a correlation id, and the structlog lines emitted while it is bound carry it.** `nexus.correlation` holds one id in one `ContextVar` (32 lowercase hex characters); the CLI group callback and each `tools/call` bind a fresh one and reset it by token when the invocation or call ends, so nothing stays bound afterwards. A structlog processor adds `correlation_id` to a line emitted while an id is bound, unless the line already carries that key. Lines emitted outside an invocation or a tool call, and stdlib log records that do not go through structlog, carry no id. Nothing sends the id to the engine yet. RDR-167, Phase 1.
