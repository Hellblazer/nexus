### Changed

- **First-run messages and help say what happens and what to do** (nexus-f3yqd.6). The setup fallback no longer talks about which launcher started the MCP server. A build with no pinned engine tag says it is a source or development build and how to find the engine tag, instead of printing a placeholder tag. `nx init --yes` says the storage service then starts each time you log in, and the `--force` hint says it replaces the autostart unit file already installed and when that helps. `nx upgrade --skip-t3` lists what it skips, says the data steps still run and the old service keeps running; `nx upgrade --yes` says nothing asks for it today, and `nx upgrade --help` no longer prints the developer notes. The plan-library check in `nx doctor` suggests `nx plan reseed` without a flag it did not need. No behaviour changes.
