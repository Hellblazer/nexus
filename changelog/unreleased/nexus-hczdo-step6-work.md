### Added

- **Registered work: dispatched agents and CI waits are listed by identity, and a dead owner's row reads stale (RDR-253 Step 6).** `nx identity work` takes a new kind, `agent`: the SubagentStart hook registers `agent:<agent id>` running and the SubagentStop verb marks it done, once each and never blocking the dispatch (an engine from before this release answers `bad_kind`, which is logged and ignored; the engine kind needs an engine release, `identity-005` widens the table's CHECK). `nx ci wait` registers a `wait` row `ci:<branch>@<sha>` for its run and ends it at every exit, a TERM included. A running wait, lab run, agent or watcher row now reads stale when its registering process is gone or was replaced (the process an owner record names, or the `<host>:<pid>:<started>` ref `lab-remote` registers), or when nothing has written it for 12 hours; `nx identity work list` marks it stale with the reason. `scripts/claude-restart-sessions` lists a stale row and does not block the ready check on it, and an agent row blocks it like a lab run does.
