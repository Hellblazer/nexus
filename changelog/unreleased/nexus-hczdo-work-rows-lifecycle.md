### Fixed

- **Registered work rows now end with their work, so a restart never needs anyone to mark them by hand.** The SubagentStop hook and the `nx ci wait`, `nx tuple wait` and `nx identity work run` labels retry a failed end once on a longer bound, and log one that still fails. `nx identity work done` and `forget` take `--identity ID` for a process that lost its session (an orphaned lab-remote's done used to change nothing). A new reap closes a running wait, lab run, agent or watcher row whose work has ended (its process is gone, it predates the session, or for an agent, the session transcript records its end), the way its registrar would have, and logs a count. Worktree rows are never reaped. Every SessionStart reaps the session's own rows in a detached child, `nx identity work list --reap` reaps before it lists, and the restart's gate reads with `--reap` (its `--status` and `--dry-run` only read). The restart script retries a work read that times out (5 s, then 30 s) and names why a list could not be read. It holds that one session back instead of refusing the whole batch. The readiness ask no longer tells sessions to mark stale rows done (nexus-hczdo).
