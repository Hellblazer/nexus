### Added

- **Identity scratch, per-identity T2, memberships and background work (RDR-253 Step 6, nexus-hczdo.1.9).** `nx scratch --scope identity <verb>` (and the `scratch` MCP tool's `scope` argument) works in the scratch of the session's identity, the T1 scope `identity:<id>`: it survives `/clear` and a restart, a session's end never closes it, only the identity's own process can write it, and a `claude -p` child reads its parent's scope and cannot write it. A process with no identity gets an error, never the session scope. `nx memory put|get|search|list --mine` works in the project `identity/<id>`, keyed by id so a rename moves nothing. `nexus.identity.membership` joins, leaves and lists group memberships through the engine's fenced membership routes (a write by a non-owner is refused).
- **`nx identity work` and `nx identity may-stop`.** A session registers what it owns as `identity_work` rows: `register`, `done`, `forget`, `list [SEAT] [--session ID] [--running] [--json]`, `owners`, and `run --kind K --ref R -- COMMAND` (registers, runs, marks done, passes the exit status through). Kinds are `worktree`, `tmux`, `watcher`, `wait` and `labrun`. `may-stop --kind K --ref R` exits 1 naming the owner when another identity owns the resource with running work and a live holder, and 0 otherwise; it reads ownership from the rows and liveness from the holder check, never from `ps`, a name pattern or a directory. The `git-worktrees` skill registers each worktree it creates and `finishing-branch` asks `may-stop` before removing one; `nx tuple wait` labels its wait; the restart sandbox registers its private tmux server and asks `may-stop` before `kill-server`.
- **A running row of an identity that is not alive is stale** and every reader ignores it, so a crashed session's work never reads as busy forever. `nexus.identity.ops.is_alive` is the one check (an unreadable holder counts as alive).
- **The restart script reports running work.** `claude-restart-sessions --status` lists each target's running work under its row, and `--ask-ready` tells each session its own list. The restart's refusal criteria are unchanged: nothing reads this report.
