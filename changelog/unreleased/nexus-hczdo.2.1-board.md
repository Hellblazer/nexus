### Removed

- **The threads board's `session:` line is no longer a key.** The compaction checkpoint, `nx ask` answer routing, the console, the due-date hook and the aura threads block find an entry by its `identity:` line only. An entry that has a `session:` line and no `identity:` line is not found, and a session that no token file binds to an identity finds no entry; `nx ask answer` refuses an ask in such an entry. `nx ask show --json` and `nx ask list --json` no longer carry `session_id`, `nx ask show` no longer prints `asker session:`, and an answer record is titled `<identity>/<ask id>/<version>` only. The console lint rule `no-session` is now `no-identity`, and `duplicate-session` is gone. Put `identity: i<n>` (the id `nx identity show` prints) on your board entry; an older `session:` line is ignored (nexus-hczdo.2.1).
