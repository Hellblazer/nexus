### Removed

- **A `/clear` no longer leaves a `cleared.<session id>` record, and the drain hook no longer empties old session mailboxes.** Mail is addressed to an identity, which survives `/clear`, so nothing is stranded (RDR-253 Phase 2, nexus-hczdo.2.1). SessionStart stops recording the previous session id, both drain hooks (the plugin script and the `nx-hook` verb) stop reading and pruning `cleared.*` records, and SessionStart deletes the ones an older client left that are over an hour old (a younger one stays: an 8.5.x session between `/clear` and its next prompt still reads its own). The tuple-watch session marker stays, for a send's default `from` without an identity and for `nx tuple wait`'s default target. Mail an older client sent to a `mailbox/<session id>` before this release is no longer drained and expires after its 7 days. While 8.5.x and 8.6 clients run together, mail an 8.5.x client addresses to an 8.6 session's session UUID is not delivered either (the sender sees success; a send by name or identity id is delivered). A pending-ack file left for a pre-upgrade session mailbox is dropped: a row consumed but not yet rendered when the client upgraded is not recovered.
