### Removed

- **A session id is no longer a mail address, and `nx tuple directory` is gone.** Mail goes to an identity (RDR-253 Phase 2, nexus-hczdo.2.1). `mailbox_send` takes an identity id (`i` and digits), an agent id, or a seat's name (resolved through its alias, as before); a session id is refused, with a message naming the identity that session is bound to, and a name no seat holds is refused instead of falling back to the old `directory/<name>` holder. Replying to a message whose `from` is a session id means sending to that session's identity, which the refusal names. The drain hook and the channel deliver `mailbox/<identity>` alone, so a session bound to no identity receives no mail until it binds. `nx tuple directory NAME` is removed with the lease it read, and the SessionStart line no longer asks the model to call `tuple_subscribe("mailbox/<name>")`.
- **`nx tuple wait` watches the bound identity's mailbox.** `--session SESSION_ID` now names the session of an identity rather than a mailbox; without it the wait uses the identity this process is bound to, and with no identity the flag is required (nexus-hczdo.2.1).
