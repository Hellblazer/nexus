### Removed

- **The `~/.config/nexus/current_session` file is gone (RDR-253 Phase 2, nexus-hczdo.2.1).** SessionStart no longer writes it and nothing reads it, so a second Claude window can no longer overwrite the session another window's tools resolve. A process finds its session in its environment (`NX_SESSION_ID`, then `CLAUDE_CODE_SESSION_ID`) or in its own identity token file, through `nexus.session.resolve_session_id` (which replaces `resolve_active_session_id`; `read_claude_session_id`, `write_claude_session_id`, `claude_session_file`, `CLAUDE_SESSION_FILE` and `mark_mcp_server_process` are removed). A process with neither resolves nothing: T1 metadata and tier-write rows say `unknown`, and `nx tier-status` with no session resolved that way exits 1 asking for `--session`, `--last` or `--since`. Its default is the session id the chain resolves (environment, then the token file), not an identity: tier-write rows are keyed by session. A stale `current_session` file on disk is ignored and can be deleted.
