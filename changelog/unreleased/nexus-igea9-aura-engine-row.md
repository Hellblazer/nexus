### Fixed

- **An aura that matches `from = "engine"` no longer fires or clears on a row carrying a client session stamp.** `from` is a dimension the writer types, so any session could post `from=engine` on `board/ci/nexus-develop--owner` and set or clear the `ci_develop_red` block. The aura runtime now also requires the row's stamp: the engine renders `sender_session` and its own rows carry none, so a row with a session stamped on it, or from an engine that renders no stamp, is ignored, with one debug line per row. A client that holds no live session writes a null stamp too, so this check alone does not prove the engine wrote the row; an engine-side refusal of client writes that claim `from=engine` closes that case and ships with the next engine release (RDR-252 critique S3, nexus-igea9).
