### Added

- **An aura can name every base your groups serve with one file (RDR-252 "Aura per base", nexus-igea9).** A trigger may carry `{serves}` once inside its topic (`board/ci/{serves}--owner`). A template names no group (it carries no `[load]` table): for every live group the session belongs to, the loader expands it into one aura per base in that group's `serves` list, named `<aura>@<base>`, each on its own concrete subspace, in its own threads block and with its own group's verdict. `display.threads` carries `{base}` and optionally `{branch}`; `self.branch` maps the base's branch into a procedure argument, and a base whose branch the procedure would refuse is left out at load. Any other brace in a subspace, a template with a `[load]` table, and `self.branch` outside a template are refused. `nx aura check` validates a template against the groups the checking identity belongs to: a session in no serving group is a warning, a base whose expansion is rejected is a refusal; `nx aura list` shows each base with its group. `ci_develop_red` and `ci_develop_nudge` are now templates, so a session loads one copy per base its groups serve; the notices name the base's branch instead of "Develop" (`ci_red_notice` and `ci_red_nudge` take an optional `branch`, default `develop`).

### Changed

- **The two shipped CI auras write a threads block per base.** A session serving `nexus-develop` now has `## aura: develop CI red (nexus-develop)` and `## aura: develop CI nudge (nexus-develop)` where it had `## aura: develop CI red` and `## aura: develop CI nudge`; the aura names in the state file and the channel notice are `ci_develop_red@nexus-develop` and `ci_develop_nudge@nexus-develop`. The config key is unchanged: `auras.ci_develop_red` and `auras.ci_develop_nudge` still turn them on.
- **The first expansion removes the old blocks.** A session that already had `## aura: develop CI red` or `## aura: develop CI nudge` in its threads entry has them removed from its own entry when the template first expands, so only the per-base heading remains.
