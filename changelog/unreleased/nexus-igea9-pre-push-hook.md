### Added

- **A managed `pre-push` hook for every repository the CI board covers (RDR-252).** It runs `nx ci check-hold` and refuses a push to `develop` or `main` while a red the pusher did not cause is open (the refusal names `NX_PUSH_RED_FIX='<reason>' git push` for a push that is the fix); a refused push writes no record. Once a push is allowed, a detached job waits for the push to exit and the remote branch to show the pushed tip, within ten minutes and with a watchdog on every remote call, and then runs `nx ci record-push`. `nx hooks install --pre-push` installs only this hook, anywhere; `nx hooks uninstall --pre-push` removes only it, and a hook file that was there before gets its bytes back. `nx upgrade` installs it only in a registered repo whose base a group you belong to serves and whose hooks directory is the repo's own, says in one line why it installed nothing (no identity, groups unreadable, a shared `core.hooksPath`, a non-shell hook), and rewrites a stanza already there. `nx hooks update`, `status` and `nx doctor` cover it, and `nx doctor` keeps its indexing hint for a repo that has only this hook. The stanza goes ahead of an existing `pre-push` body and in the `core.hooksPath` directory, and the install warns when that file is tracked by the repo. `scripts/git-push-develop.sh` marks its own push with `NX_PUSH_VIA_SCRIPT=1`, so a push it records is not recorded again by the hook.
