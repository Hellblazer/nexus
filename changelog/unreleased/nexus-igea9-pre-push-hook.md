### Added

- **A managed `pre-push` hook for every repository the CI board covers (RDR-252).** It runs `nx ci check-hold` and refuses a push to `develop` or `main` while a red the pusher did not cause is open; a refused push writes no record. Once a push is allowed, a detached job waits at most ten minutes for the remote branch to show the pushed tip and then runs `nx ci record-push`. `nx hooks install --pre-push` installs it anywhere; `nx upgrade` installs it only in a registered repo whose base a group you belong to serves, and rewrites a stanza already there. `nx hooks update`, `uninstall`, `status` and `nx doctor` cover it. The stanza goes ahead of an existing `pre-push` body and in the `core.hooksPath` directory. `scripts/git-push-develop.sh` marks its own push with `NX_PUSH_VIA_SCRIPT=1`, so a push it records is not recorded again by the hook.
