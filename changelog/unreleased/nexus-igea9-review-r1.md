### Fixed

- **The develop-red hold and the push record are sturdier (RDR-252 review round 1).** `nx ci check-hold` marks an override with one exact `PUSH_RED_FIX_APPLIED` line (and a flag nothing needed as `PUSH_RED_FIX_UNNEEDED`), so the push script no longer matches free text; an identity that cannot be read warns and never refuses, a genuine no identity is refused with a pointer to `nx identity show`, and a suspect with no attributable push record is named with the way out. `nx ci record-push` cuts the `red_fix` reason by UTF-8 bytes to fit the board's 1024-byte body cap (control characters become spaces, the fallback record keeps it), says whether the record is stamped (`PUSH_RECORD_UNSTAMPED` when nothing stamped it), and `git-push-develop.sh` falls back to the legacy `nx tuple out` record when the installed nx has no `ci record-push` (`PUSH_RECORD_LEGACY`). (nexus-igea9)
- **`nx ci` reads a remote's repo one way.** `ack`, `wait`, `record-push` and `check-hold` share one URL parser and lower-case the repo name as the CI adapter does (`ART.git` pushing `main` is the board `art-main`); `nx ci wait` with no `--branch` waits on develop when `origin/develop` exists, else on the branch `origin/HEAD` names, else refuses naming `--branch`; `nx group ack-times` marks a disclaim that is not from the owner's stamped session `(ignored: not the owner)`. (nexus-igea9)
- **Confirmation round fixes.** The fallback push record says what is true: written without the T1 session header, still stamped by an identity token when the process holds one, else unstamped (read off the outgoing request headers in tests); a `--red-fix` that is blank once cleaned counts as no flag; a suspect whose stamp is no session id or is not in the session index is named unattributed instead of making the whole hold check unchecked; a failed identity-record read for a delegated child is `PUSH_GATE_UNCHECKED` in `nx ci check-hold` (`nx ci ack` unchanged); an identity-token resend without the token counts toward `PUSH_RECORD_UNSTAMPED`; explicit `--repo`, `--base` and `--topic` are lower-cased like derived ones. (nexus-igea9)
