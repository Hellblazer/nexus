### Fixed

- **An ack to `board/ci/<topic>--owner` carries the identity the engine counts it for, whatever the client typed.** `nx group ack-times` counts an ack only when its `from` is the owner's identity id, so an ack typed `from=marginalia` (sha ae619ef, 2026-11-20) was counted as no ack, though the deadline timer, which maps the row's session stamp, had counted it. The engine now sets `from` on a `kind=ack` write to an `--owner` topic to the identity the deadline timer counts the row's session stamp for (a delegated `claude -p` child counts as its parent), with or without an identity token: it fills `from` when absent, overwrites a different value (and logs the old and the new at info), and refuses nothing. This covers `out` (also `mode=replace`) and an `ack` reply. A stale token from a superseded generation still stamps its old session, so it is labelled with its identity. A stamp that maps to no identity (an unknown minted session, no credential), other kinds and other topics are unchanged. Ships with the next engine release (RDR-252, nexus-igea9.4).
