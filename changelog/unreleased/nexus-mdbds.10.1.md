### Added

- **The aura file parser and loader** (nexus-mdbds.10.1, RDR-249 Phase 1 Step 1). The new `nexus.auras` package parses `<name>.aura.toml` against the closed key set of Technical Design 1 (with `[limits]` from Technical Design 6, each no higher than RDR-242's default) and loads it from both procedure roots. A file with an unknown key, a missing required key, a wrong type, a name that breaks RDR-242's name rule, a trigger subspace that is not one concrete `board/<topic>` or `board/ci/<topic>`, a mapped `now` or `repo`, or an argument source outside the four forms is refused with an error that names the file and the key. The roots, name rule, shadow refusal and repo-root switch are the procedure library's: `nexus.lua_runtime.library` gains suffix-agnostic `find_file` and `list_files`, and `find` and `procedures` are unchanged `.lua` wrappers. Nothing runs an aura yet; `nx aura check` and `nx aura list` follow.
