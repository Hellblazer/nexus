### Fixed

- **The native engine binary now carries the `db/rdr229/` resources, so RDR-229's boot-time completion work starts.** `resource-config.json` had no pattern for `db/rdr229/`, so the GraalVM binaries of engine-service v0.1.200 to v0.1.202 lacked `p33a-fk-twins.tsv`: `FkTwins` threw "is not on the classpath" from its static holder, `CompletionBootWork.atBoot` failed with `ExceptionInInitializerError`, and the engine logged `event=rdr229_completion_not_started` and never published `rdr229_completion` on `GET /v1/status`. JVM tests read the files from the classpath and never saw it. The pattern `db/rdr229/.*` is added, `ResourceConfigCensusTest` fails on any file under `src/main/resources` that no `resource-config.json` pattern, pom `-H:IncludeResources` buildArg or named not-read-at-run-time entry covers, and `service/native-smoke.sh` now fails the native boot when `rdr229_completion` is absent from `/v1/status` after a 60 s poll or the engine log carries `ExceptionInInitializerError`, "is not on the classpath" or `rdr229_completion_not_started`.
