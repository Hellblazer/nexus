### Changed

- **The two move routes refuse, by id, a collection the request did not name.** RDR-229 P3.5c. Once gate 3 latches, `POST /v1/catalog/documents/move` and `POST /v1/catalog/owners/move` lock by registry id every collection the move writes in before any document row: the documents' own, and the collections of their aspect rows, highlight rows and alias rows. A collection whose registry row is retired now answers 409 `collection_superseded`, and an id no registry row holds answers 404 `unknown_collection_id`, with the bodies the by-id routes send; a dry run is refused too, and nothing is written. A collection that arrives between that read and the document locks answers the routes' existing 409 (run it again). Before the latch the routes are unchanged (nexus-p2m1x.25).
