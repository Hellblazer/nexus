### Changed

- **`nx taxonomy project`, `--backfill`, `--prune-below-threshold` and `nx taxonomy audit` read a collection's default projection threshold from its catalog row (RDR-229 P2.4).** A collection's `content_type` picks knowledge 0.50, docs/rdr 0.55, code and anything else 0.70, even when its name's prefix says otherwise; the name's prefix answers only for a collection with no catalog row or when the listing cannot be read (logged once). An explicit `--threshold` is unchanged. `--prune-below-threshold` without a source now prunes each collection at its own threshold, by full collection name, instead of once per `code__`/`knowledge__`/`docs__`/`rdr__` prefix. The engine matches a prune by name prefix, so a collection whose name is a prefix of another's (`...__v1` and `...__v10`) is skipped, with a printed line, when pruning it would also delete rows the longer one's lower threshold keeps.
