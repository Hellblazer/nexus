### Added

- **SessionStart says when the memory directory needs curating** (RDR-238 Phase 3 Step 1, nexus-qo7ie.16). In a repository whose Claude Code memory directory holds `MEMORY-ondemand.md`, the session-start output ends with one line when `MEMORY.md` is over its token budget (`memory.index_budget_tokens` in `.nexus.yml`, default 1500), a memory file is in neither index, a file that another file `replaces` is still there, or an index entry names a missing file. It reads the same directory and runs the same scan as `nx memory curate --files`, says nothing when the directory is clean, and never blocks a session. It runs inside the existing `session-start` hook, so it starts no new process; `nx-hook memory-curation-check` runs it by hand.
