### Added

- **`nx memory curate --files` lists the memory files no session that started in the window read, and T2 reads per title and per project** (nexus-qo7ie.18, RDR-238 Phase 3 Step 2). The counts come from RDR-240's `transcripts` procedure, query `memory`, over the repository's own sessions, every page joined. A read is a `Read` of the file or its load into a subagent; a read through Bash, Grep or an attachment is not counted, and the report says so. `--days` is capped at the 30 days Claude Code keeps transcripts and at the oldest session on disk, and the report prints the span and why. Without the procedure runtime, on a failed query, with no session of the repository in the window, for a memory directory the query cannot recognize (no `/memory/` component) or on native Windows, the rows say `not available` and why, never an empty list, and the command still exits 0.
