### Removed

- **`nx rdr preamble rdr-research -- add` no longer records a research finding** (nexus-qo7ie.33, RDR-240 Technical Design 7). A finding passed as shell words was split by the shell: a semicolon in one ran a stray `git stash`, and three records were truncated. Every `add` form now exits nonzero and prints the replacement: `/conexus:rdr-research add <id>`, which runs the `research_add` procedure (from a shell, `nx run research_add --args-file <json>`), reads the returned title back, and writes the returned record unchanged with `memory_put`. The record has the same shape the CLI wrote, except that `classification` and `method` are now both required (the CLI let either be left out). The plugin's skills switched to this path in conexus 8.0.0: a session on a conexus plugin older than 8.0.0 still runs the removed form and meets the refusal on every finding, so update the plugin to 8.0.0 or later alongside this release. `nx rdr preamble rdr-research -- <id>` still prints the RDR's research context, and the gate and fix preambles now point at the skill.
