### Changed

- **`transcripts.sessions` skips decoding attachment lines no selected field reads** (nexus-qo7ie.39, follow-up to nexus-qo7ie.37). An attachment line is skipped while `instruction_loads`, `deferred_tools` and `deferred_tools_dropped` are all unselected. Its type may come from the opening run of members and the members after the last nested value supply what is missing (stamp and ids), when the text proves them top-level. Records are unchanged; a line whose stamp sits before a nested array (Claude Code writes `rendered` there) is still decoded, and user and assistant lines are always decoded. Measured gain on a 30-day tools scan: about 3 to 4%. A crash-resumed line (a torn write with the next record appended to it) keeps the resumed record's type, stamp and ids where the decode drops it: the accepted residual class from nexus-qo7ie.37.
