### Added

- **`link_audit` reports `dchash:` spans that no longer resolve.** The audit result, `nx catalog link-audit` (a `Stale dchash:` count line, and a `Stale dchash spans:` list when it is above zero) and `--json` carry `stale_dchash` (one row per span: `from_tumbler`, `to_tumbler`, `link_type`, `side`, `span`, `status`) and `stale_dchash_count`; both are always present. The status is `malformed`, `missing` (the document is gone), `unreadable` (no source file, or one that cannot be read or is not UTF-8), `changed` or `out_of_range`. Each document is read once, however many spans it has. The report reads source files on the machine it runs on, and an engine error fails the audit instead of listing spans as stale. The `catalog_link_audit` tool's description and `docs/catalog.md` no longer name `stale_spans` and `stale_chash`, which the code stopped returning (nexus-qrg1r.2, RDR-171).
