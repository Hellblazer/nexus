### Added

- **A session start tells you when a conexus settings file has a problem.** A SessionStart hook (`conexus/hooks/scripts/settings_notice.py`, standard library only) prints one message on startup, resume and clear when `.nexus/project.json` or `conexus.json` has a problem: an unknown or misspelled key (`subagent-git` points to `subagent_git`), a bad value, a file that cannot be read, or no account home. Each line names the file, the problem and the value used; file text in it is cleaned, quoted and cut to 60 bytes. The model gets one line with the count, the file names and the pointer, never file text. The pointer is `nx settings show` when the installed `nx` has it, else the plugin's own `_audience.py show`. Nothing is printed on compact or fork, or when nothing is wrong.
