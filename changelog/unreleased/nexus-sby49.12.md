### Added

- **The first prompt of a session tells you when a conexus settings file has a problem.** A UserPromptSubmit hook (`conexus/hooks/scripts/settings_notice.py`, standard library only) prints one message on a session's first prompt when `.nexus/project.json` or `conexus.json` has a problem: an unknown or misspelled key (`subagent-git` points to `subagent_git`), a bad value, a file that cannot be read, or no account home. Claude Desktop shows a prompt hook's message and hides a session-start hook's, which is why this is a prompt hook; the CLI shows it too, once. Each line names the file, the problem and the value used; file text in it is cleaned, quoted and cut to 60 bytes. The model gets one line with the count, the file names and the pointer, never file text. The pointer is `nx settings show` when the installed `nx` has it, else the plugin's own `_audience.py show`. A later prompt of the same session exits before it reads any settings, and nothing is printed when nothing is wrong. The session's mark is one empty file, in the audience log marks directory when `~/.config/nexus/logs` exists and in the system temporary directory otherwise.
