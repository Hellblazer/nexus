### Added

- **`nx settings show` and `nx settings check` read the conexus project and user settings files.** `show` prints both file paths, every setting's value and source, the texts the hooks print under their labels, every problem, the retired files that still exist, and the plugin's and the CLI's versions with a warning when they differ; `--json` gives the same report. Its output equals the plugin's own `python3 <plugin root>/hooks/scripts/_audience.py show` except for the version lines. `check` prints only the problems and exits 1 when a settings file has one; a problem in the machine (no account home, a missing remote branch in a shallow clone, telemetry on with no engine under the account's config directory) is printed but does not change the exit code. `nx config --help` points to it.
