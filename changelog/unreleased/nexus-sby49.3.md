### Changed

- **The plugin's maintainer-only rules and telemetry no longer reach other users.** SubagentStart's Git and Search scope rows and its brief check, SessionStart's dispatch-protocol sentence, SubagentStop's nudge for Claude Code's built-in agents and its dispatch record, and the routing_events rows the guards write are now sent only when the OS account has the maintainer flag or the checkout carries the nexus marker (`.nexus/dev-process.json`). A conexus agent that stops without a T1 write is still nudged, in text that no longer names a bead id. The relay's Bead field takes a tracking id as well as a bead id. SessionStart names the `beads` and `rdr` topics only in a project that has beads (a `.beads/` directory or `bd` on PATH) or an RDR directory, and prints one line when the nexus marker is the only reason a session is held to nexus's rules. The retired `share_t1` note is gone. (nexus-sby49.3)
