### Changed

- **The development process reaches every user, with nexus's own words taken out.** Against 8.5.7: SubagentStart's Search scope row and its brief check (four questions: consumers, final point, bounds, state) go to every implementer dispatch, SessionStart's T1 dispatch-protocol sentence goes to every session, and SubagentStop's T1 nudge covers every agent type (turn it off with `t1_nudge: false` in `conexus.json`). The Git row of the Orchestration table is added where the strict guard runs. A project can add its own brief questions and a worktree preflight command in `.nexus/project.json`. The text no longer carries bead or RDR ids, "hook-ENFORCED", or the question about local and cloud modes, and the Phase Boundary Gate's closing sentence no longer tells a nexus incident. The relay's Bead field takes a tracking id as well as a bead id. SessionStart names the `beads` and `rdr` topics only in a project that has beads (a `.beads/` directory with `bd` on PATH) or an RDR directory. The retired `share_t1` note is gone. (nexus-sby49.3)
- **Nothing is sent to your engine unless you say so.** The routing_events rows the guards write (they carry the command fragment) and the dispatch record (agent type and T1 put count) are sent only when `telemetry` is true in `~/.config/nexus/conexus.json`; the default is off, and a project file cannot turn it on. (nexus-sby49.3)
- **Other text changed for everyone.** The `_OPERATORS` heading no longer ends in `(RDR-080)`; the T1 contract's example tags read `my-task,review-r1` where they read `nexus-abc,review-r1`; the auto-link recipe no longer cites a bead id; the SubagentStop nudge asks for "the tags your brief names" where it asked for "your bead id and write-back". (nexus-sby49.3)
