### Changed

- **The per-collection search route is now opt-in** (nexus-tu8wp.3). Searches take the batched `/v1/vectors/search` path again by default. On the MCP no-rerank shape over the cloud's many small collections the route measured about 2x slower (warm, median 2.77 s against 1.42 s; 105 exact scans against a few combined statements) and returned the same page (overlap 10 of 10). The CLI rerank shape is unmeasured: that leg was voided by Voyage 429s. Set `NX_SEARCH_PER_COLLECTION=1` (or `true`, `on`, `yes`) to use the route; every other value, and unset, keeps the batched path. The route code stays, dormant. `scripts/measure_search_per_collection.py` sets the variable for its route runs and clears it for its batched runs.
