### Changed

- **`nx catalog list --meta` asks the engine instead of reading every document (RDR-241 Phase 2, nexus-uwggq.2.14).** One request to `GET /v1/catalog/docs/by-meta` returns the requested page in tumbler order with the exact count, so the `Next page: --offset N` line comes from the route's count. A `-n` above the route's 1000-row bound is read as several pages. `--meta` with `--sensitive` sends `sensitive=true` on the same request, so it works past 10,000 sensitive documents; `--sensitive` without `--meta` and `--meta` with `--owner` are unchanged. The command needs an engine with the metadata route (engine-service 0.1.197 or later): on an older engine it exits non-zero naming the route and the engine release, and when the engine times out it says so. It never falls back to a scan. A `-n` below 1, a negative `--offset` and an empty `--meta` value are usage errors with `--meta`.
