### Fixed

- **An unattended `nx upgrade` on a managed service skips the RDR-192 manifest backfill quietly and `nx doctor` says so once.** The backfill never runs unattended on a managed service: its census is one engine scan per collection and its data move belongs to an interactive `nx upgrade`. But the rung declined only after the walk had already picked it as pending, so every session start after a version bump logged a `ladder_rung_deferred` warning (608 on one install over five weeks) and told the user nothing. The rung now declines in its check step, as the other data rungs do: the session-start upgrade skips it with no warning, and `nx doctor`'s "Upgrade ladder" row lists `rdr192-manifest-backfill` under "not checked" with the fix, an interactive `nx upgrade`. A completion recorded at an earlier version still answers the engine's reaper gate, which reads a record at any version; with no completion recorded the reaper stays refused until that interactive run.
