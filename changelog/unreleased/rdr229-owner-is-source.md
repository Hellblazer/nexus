### Changed

- **An imported collection's documents are registered under the collection's source.** A repo's `code__`, `docs__` and `rdr__` collections go to the repo owner, found from the export file's owner header, or from the `<name>-<hash8>` in the collection name, and a docs corpus goes to its corpus curator. Only a collection with no source at all still falls back to the knowledge curator, and then `nx store import` logs a warning and prints it in the summary; that includes a `docs__` collection whose name carries an owner id instead of a corpus name. Exports now record the repo owner in the file header, and older files import as before (RDR-229).
- **`nx index repo` fills in a repo owner's missing root.** An owner that an import registered without a root gets the repo's real path on the next index run; an owner that already has a root is left alone (RDR-229).
- **Known limitation for old export files.** A `docs__` collection from an export file that has no owner header, imported before any `code__` collection or repo owner exists for its `<name>-<hash8>`, is given its corpus curator as owner. `nx store import` warns when this happens and names the remedy: import the repo's `code__` file, then remove the `docs__` collection and import it again (RDR-229).
- **An old `rdr__` export file of a repo this install does not know.** It goes to the knowledge curator, and `nx store import` warns. Import the repo's `code__` file first to have it registered under the repo (RDR-229).
- **A curator owner is no longer replaced by the owner of documents that arrive later.** A collection's owner is set once, when it is registered. Only an owner that is not a tumbler (a slug, empty or a placeholder) is still derived from the collection's documents (RDR-229).
- **An engine data move re-assigns a repository's collections to the repository's owner.** An old bulk import left some of them under a curator; the move runs once on engine start and puts each under the repo owner. A collection whose place under the repo owner is already taken by another live collection of the same type and model stays with its curator, and is listed in `nexus.gc_audit` with operation `rdr229_reown_skipped` (RDR-229).
