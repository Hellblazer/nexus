### Fixed

- **A second clone of a repository in a folder with the same name no longer takes the first clone's owner over.** Two clones such as `~/work/nexus` and `~/scratch/nexus` shared one owner, and registering either one swapped the owner's root and hash to its own, so the second clone's copies of the files both clones hold were never documents of their own. When another owner of the same name records a root that is a different live git work tree on this machine (or a root `nx` cannot read), `nx index repo` now registers the repository under its own owner, named `<folder>-<repo hash>`, and leaves the first owner alone. A root that is gone, or the same clone reached through a symlink, keeps the one owner as before. Owners two clones already share are not split after the fact (RDR-254 Gap 4).
