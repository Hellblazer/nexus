### Added

- **Every generation cleanup leaves a record in `~/.config/nexus/logs/install-gc.log`.** The SessionStart sweep, `nx self gc`, `nx self install` and the bootstrap rebuild all reap through one rule set, and the sweep discarded its output, so a generation removed under a live session left no trace. Each run now appends JSON lines to that file (under `NEXUS_CONFIG_DIR` when set) as it goes, each flushed to disk before the next step: a `gc_reap_begin` line before each delete starts, `gc_reaped` after it (or `gc_reap_failed`), and one `gc_run` summary. The lines name the generation, its stamp, the reason, the holder count, the process census (state, why it failed, how long `ps` took, rows), the caller (`self-gc-hook` for the SessionStart sweep, `self-gc` by hand, `self-install`, `bootstrap`), the nx that ran it (generation and version), the parent process chain, and a map of every held generation to its pids. A run that removes nothing still writes the summary, a missing tools directory is recorded, `--dry-run` writes nothing, and the file rotates to `install-gc.log.1` past 1 MB. A record that cannot be written never stops the cleanup.
