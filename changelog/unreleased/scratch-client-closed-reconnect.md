### Fixed

- **The T1 `scratch` tool no longer fails for the rest of a session after one `[Errno 2] No such file or directory`.** A long-lived MCP server that rebuilt its scratch client (on a rotated session token or an engine restart) re-read the TLS CA bundle from the nx install it started from; once that install had been removed, the rebuild raised a pathless ENOENT after the old client was already closed, and every later scratch call answered "Cannot send a request, as the client has been closed." until the session restarted. The scratch and token-admin stores now share the process-wide SSL context the T2 stores use (the bundle is read once per process), build a replacement client before closing the old one, rebuild a client that was closed under them on the next call, and name the CA bundle's path when it cannot be read.
