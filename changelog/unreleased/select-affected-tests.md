### Added

- **`scripts/select_affected_tests.py` picks the test files a change can reach, so a lane runs them before stacking or pushing.** `pytest $(scripts/select_affected_tests.py --base origin/develop)` selects the files that import a changed module directly or through any import chain (built with `ast` over `src/nexus`, `tests`, `scripts` and `conexus`, cached per file), the files that name a changed toml, ledger, doc, workflow, fixture or shell script, and what `scripts/meta_tests.py` and `scripts/select_docs_reader_tests.py` pick. A change to `tests/conftest.py`, `pyproject.toml`, `uv.lock` or a helper the root conftest loads prints `tests`; a `service/` change prints the `scripts/mvnw-leased.sh` line for the touched engine classes and selects the Python files naming a `/v1` route the changed Java serves. `--explain` gives the reason per file, `--range` and `--files-from` take a push or a file list, and `--max-depth` bounds the import chain for a quick first pass.
