### Added

- **`nx brief [TOPIC]` and the `brief` MCP tool.** Topics `memory`, `beads`, `caps`, `map`, `rdr` and `me`, each rendered by the same functions the hook used; `nx brief` with no topic lists them, and `me` prints this seat's `startup` note (`identity/<id>`) as data. One JSON line per call goes to `<config>/logs/brief.log` for the 30-day keep-or-drop review. The MCP tool is read-only and is not in the auto-approve allowlist.
