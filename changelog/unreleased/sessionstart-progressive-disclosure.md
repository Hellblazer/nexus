### Changed

- **SessionStart prints only rules and this session's state; reference context is on demand (`nx brief`).** On resume, clear and fork the always-on nexus output falls from about 5.6-5.8 KB (7-9 KB with a live T2 scan, the RDR line and the bd primer) to about 2.9-3.1 KB, 3.3-3.5 KB on clear with its resume line. The `session-context` hook now prints the T1 contract, the threads due, the identity-notes line and one static index line (`More on demand: nx brief <topic> ...`); the hygiene block is unchanged. The T2 memory scan, ready beads, the `bd prime` primer, the capabilities block and the Knowledge Map are no longer injected, and a healthy RDR tree no longer prints its count line (the remedy, the unchecked-fix lines and the late-T2 note still print). No rule moved behind a brief. The SessionStart byte ceilings in `tests/hooks/test_session_start_combined_budget.py` are lowered to the measured values.
