### Changed

- **If you run nx inside a container, its daily install ping now stops; set `NX_TELEMETRY=1` (for example `docker run -e NX_TELEMETRY=1 ...`) to turn it back on.** The ping also skips pytest runs, lab runs and CI, so test and build runs no longer count as installs. Container detection is best effort, per runtime. Run `nx telemetry status` to see which signal fired; it now ends with a hint to set `NX_TELEMETRY=1` when one did, and `nx telemetry on` prints the same hint when an automation signal still keeps the ping off. `NX_TELEMETRY=1` overrides only these automation skips: `NX_NO_TELEMETRY`, `nx telemetry off` and the dev-checkout skip still win over it, and `NX_TELEMETRY=0` (or `false`, `no`, `off`) turns the ping off. The existing opt-outs and their `status` reasons are unchanged. (conexus-momd; Sam 2026-11-24)
